# InfraLens: Power BI Desktop Setup & Data Modeling Guide

This guide details the complete procedure for building and configuring the **4-Domain Infrastructure Analytics Dashboard** in Power BI Desktop, using the datasets generated by the InfraLens automated pipeline.

---

## 1. Connecting Power BI to InfraLens Data

There are two equally supported methods to ingest data into Power BI Desktop:

### Method A: Fast Ingestion via Python Script Connector (Recommended)
1. Launch **Power BI Desktop**.
2. Click **Home > Get Data > More... > Other > Python script** and click **Connect**.
3. In the script dialog, paste the code from [dashboard/powerbi_connector.py](file:///c:/Users/aravindhan.chandrase/Desktop/Psiddhi%20Sem3/InfraLens/dashboard/powerbi_connector.py).
4. Click **OK**. In the **Navigator** window, check the boxes for:
   - `DailyMetrics`
   - `HourlyMetrics`
   - `AnomalyAlerts`
   - `CapacityForecasts`
   - `UnderutilizedResources`
   - `NarrativeInsights`
   - `RecentMetrics`
5. Click **Load**.

### Method B: Native Parquet / Folder Connector (Zero Code)
1. In Power BI Desktop, select **Home > Get Data > Parquet** (or **Folder**).
2. Browse to `data/processed/`.
3. Select any `.parquet` files (`daily_metrics_rollup.parquet`, `capacity_forecasts.parquet`, etc.) and click **Load**.

## 2. Data Model & Relationships (Star Schema)

In the **Model View** of Power BI Desktop, establish the following relationships to allow cross-filtering:

```text
       [AnomalyAlerts]                   [CapacityForecasts]
              │ (1:*)                             │ (1:*)
              ▼                                   ▼
        [DailyMetrics] ◄────────────── [UnderutilizedResources]
              ▲
              │ (1:*)
      [NarrativeInsights]
```

- **DailyMetrics** (Central Fact):
  - Primary Keys: `resource_id`, `metric_name`, `date`
  - Dimensions: `region`, `service_tag`
- **AnomalyAlerts**: Related via `resource_id` (Many-to-One single directional).
- **CapacityForecasts**: Related via `resource_id` (Many-to-One single directional).
- **NarrativeInsights**: Related via `resource_id` (Many-to-One bi-directional or standalone narrative card viewer).

## 3. Recommended DAX Measures

Create a new table or measure group for **InfraLens KPIs**:

```dax
// 1. Total Daily Spend
Total Daily Spend = 
CALCULATE(
    SUM('DailyMetrics'[avg_value]),
    'DailyMetrics'[metric_name] = "daily_cost"
)

// 2. Average CPU Utilization
Avg CPU % = 
CALCULATE(
    AVERAGE('DailyMetrics'[avg_value]),
    'DailyMetrics'[metric_name] = "cpu_utilization"
)

// 3. Week-over-Week Spend Delta %
Spend WoW % = 
VAR CurrentWeekSpend = [Total Daily Spend]
VAR LastWeekSpend = 
    CALCULATE(
        [Total Daily Spend],
        DATEADD('DailyMetrics'[date], -7, DAY)
    )
RETURN
    IF(
        ISBLANK(LastWeekSpend) || LastWeekSpend = 0,
        0,
        DIVIDE(CurrentWeekSpend - LastWeekSpend, LastWeekSpend)
    )

// 4. Critical Anomaly Count
Critical Anomalies = 
CALCULATE(
    COUNTROWS('AnomalyAlerts'),
    'AnomalyAlerts'[severity] = "Critical"
)

// 5. Total Identified Monthly Savings
Identified Monthly Savings = 
SUM('UnderutilizedResources'[potential_monthly_saving])

// 6. Max Projected 90D CPU
Max 90D Projected CPU = 
MAX('CapacityForecasts'[projected_90d])
```

## 4. The 4 Dashboard Pages & Layouts

### Page 1: Compute Utilization
- **Top Ribbon Cards**:
  - `Average CPU %`
  - `Average Memory %`
  - `Total Monitored VMs`
- **Main Visual (Line & Clustered Column Chart)**:
  - **X-Axis**: `DailyMetrics[date]`
  - **Values**: `avg_value` filtered by `cpu_utilization` and `memory_utilization`
  - **Legend**: `service_tag` (compute, api, development)
- **Secondary Visual (Matrix / Heatmap)**:
  - **Rows**: `resource_id`
  - **Columns**: `region`
  - **Values**: Average of `cpu_utilization` with conditional color formatting (Green <50%, Yellow 50-80%, Red >80%).
- **Slicers**: Region, Service Tag, Date Range.

### Page 2: Cost Trends & Anomaly Insights
- **Top Ribbon Cards**:
  - `Total Daily Spend (USD)`
  - `Spend WoW %`
  - `Critical Cost Anomalies`
- **Main Visual (Stacked Area Chart)**:
  - **X-Axis**: `DailyMetrics[date]`
  - **Y-Axis**: `DailyMetrics[avg_value]` where `metric_name = "daily_cost"`
  - **Legend**: `service_tag`
- **Cost Spike Highlight Panel (Table)**:
  - Table of records from `AnomalyAlerts` where `metric_name = 'daily_cost'`. Shows `timestamp`, `resource_id`, `value`, `z_score`, `severity`.
- **AI Narrative Callout Card**:
  - Multi-row Card or Text Card bound to `NarrativeInsights[insight_text]` where `scenario = 'cost_anomaly'`. Displays the plain-language Gemini explanation of the cost spike and optimization actions!

### Page 3: Capacity Patterns & Breach Forecasting
- **Top Ribbon Cards**:
  - `Resources Tracked`
  - `High Risk Count (Threshold > 80%)`
  - `Earliest Projected Breach Date`
- **Forecasting Visual (Line Chart with Reference Line)**:
  - Shows current utilization, 30d, 60d, and 90d projections from `CapacityForecasts`.
  - Constant reference line set at **80%** (SLA Safety Threshold).
- **Risk Table**:
  - Columns: `resource_id`, `current_value`, `growth_rate_per_day`, `projected_90d`, `projected_breach_date`.
- **AI Narrative Callout Card**:
  - Displays `NarrativeInsights[insight_text]` where `scenario = 'capacity_risk'` detailing why `vm-prod-02` will breach on 2026-08-31 and recommended scale-out steps.

### Page 4: Underutilization & Anomaly Alerts
- **Top Ribbon Cards**:
  - `Total Potential Monthly Savings ($USD)`
  - `Candidates for Decommissioning`
- **Right-Sizing Matrix**:
  - Columns: `resource_id`, `service_tag`, `avg_cpu`, `avg_memory`, `daily_cost`, `potential_monthly_saving`.
- **Anomaly Detection Stream**:
  - Full stream of all alerts from `AnomalyAlerts` with severity classification badges.
- **AI Narrative Callout Card**:
  - Bound to `NarrativeInsights[insight_text]` where `scenario = 'underutilization'`, detailing specific candidate VMs and decommissioning advice.

## 5. Automated 15-Minute Refresh Setup

To maintain live updates in Power BI Desktop:
1. Ensure the InfraLens scheduler daemon is running in the background:
   ```powershell
   .venv\Scripts\python.exe -m scheduler.scheduler --schedule 15
   ```
2. In Power BI Desktop:
   - Click the **Refresh** button on the Home ribbon at any time, or configure Power BI Desktop automatic page refresh (DirectQuery / local loop).
   - Every execution of the scheduler automatically overwrites the `.parquet` and `.csv` datasets in `data/processed/`, so clicking **Refresh** instantly updates all 4 dashboard pages with the latest metrics and AI narratives!
